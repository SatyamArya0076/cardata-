# 🚗 Car Price Prediction using Machine Learning

A complete machine learning project that predicts the **selling price of used cars** using regression algorithms. This notebook covers data preprocessing, feature engineering, model training, hyperparameter tuning, and performance evaluation to build an accurate car price prediction model.

---

## 📌 Project Overview

The goal of this project is to predict the resale value of a used car based on features such as vehicle age, fuel type, transmission, ownership history, and kilometers driven. Multiple regression models are trained and compared to identify the best-performing model.

---

## ✨ Features

* 📂 Data loading and exploration
* 🧹 Data cleaning and preprocessing
* 🔧 Feature engineering (Car Age calculation)
* 🔄 One-Hot Encoding for categorical features
* ✂️ Train-Test Split
* 🤖 Multiple Regression Models
* 🌲 Random Forest Regressor
* 📈 Model Evaluation using regression metrics

